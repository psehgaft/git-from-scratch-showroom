# Contributing

1. Cree una rama de corta duración.
2. Mantenga cada cambio enfocado.
3. Ejecute `./scripts/preflight.sh`.
4. Revise enlaces, comandos y manifiestos.
5. Abra un Pull Request con objetivo y validación.
6. No incluya credenciales, tokens, kubeconfigs o datos personales.

Convención de commits recomendada:

```text
feat: add a new lab capability
fix: correct an invalid command
docs: improve workshop instructions
chore: update build configuration
```
